# Hollowvale: Wildbound

Production-ready browser survival game. Open `index.html` or host on GitHub Pages / Netlify / Vercel / itch.io.

## Features
- Full survival loop (Vitality, Stamina, Sustenance, Warmth)
- Day/night cycle + dynamic lighting & torch/campfire
- Resource gathering, crafting, Hollow Stalkers, lore cairns
- Mobile + desktop controls
- Auto-save
- **Watch AI Play** mode (spectator path for companion AI)
- **Ara** free-roaming silver holographic companion in the world
- Easter eggs & secrets
- Support / Economy panel (donations + 3% future margin note)
- itch.io ready (single HTML file)

## Hosting (Free)
1. **GitHub Pages**: Push this repo, enable Pages from `main` branch root.
2. **Netlify Drop** or connect the repo.
3. **itch.io**: Zip the folder (index.html at root) and upload as HTML game. Enable donations.
4. Custom domain optional on all.

## Monetization (Day One)
Update the Support button links in `index.html` with your real accounts:
- PayPal.me
- Ko-fi / Buy Me a Coffee
- Coinbase / USDC / BTC address or NOWPayments
- Stripe Payment Link

No pay-to-win. Cosmetics and supporter badges planned. Financials protected by design (tips only, no gambling or real-money PvP). Full player economies require your payment accounts and compliance.

## Controls
- WASD / Arrows or touch D-pad
- E / Gather, Space / Strike, F / Torch, C / Craft

Built for simple access, global players, and real-world support from the first night.
